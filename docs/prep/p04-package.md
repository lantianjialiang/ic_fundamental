## 开篇

裸 Die 太脆弱，管脚也太细，不能直接给用户。**封装**把 Die 变成可焊接、可运输的器件。但封装过程本身可能键合不良、虚焊——所以封装后还要 **FT（Final Test）**。封装前的 **CP** 则是为了少封坏片。

---

## 节 1 · 为什么要封装

### 正文

封装至少做四件事（一句级）：

1. **引出**：把 Die 上的 pad 连到可焊接的脚或球。  
2. **保护**：机械、湿气、污染。  
3. **散热**：把热导到外壳 / 基板。  
4. **电气**：控制阻抗、寄生（高速时更关键，本课点到为止）。

### 互动图：`WhyPackageFig`

- 四个可点图标（引出 / 保护 / 散热 / 电气），初始选中「引出」。  
- 选中后短说明 + 简单示意图。

## 节 3 · 键合、倒装、先进封装一瞥

### 正文

- **Wire bond**：金属线连 pad 与框架/基板，经典、成本友好。  
- **Flip-chip**：Die 面朝下凸点互连，电性能更好，常见于高性能芯片。  
- **SiP / Chiplet**：多芯片进一封装；需要 KGD 与更复杂的测试策略（接 P02/P03）。

### 互动图：`BondStyleFig`

- 分段按钮：打线 / 倒装（初始打线）。  
- 切换截面简图；侧栏对比优缺点各一句。

## 节 4 · CP vs FT（对照互动）

### 正文对照

| | CP | FT |
|---|---|---|
| 何时 | 封装前 | 封装后 |
| 测谁 | 晶圆上的 Die | 已封装器件 |
| 接触 | 探针 / 针卡 | Socket（Handler 上料） |
| 目的 | 少封坏片、看晶圆良率 | 出货判定；也抓封装缺陷 |
| 程序 | 常较快、覆盖按策略裁 | 通常更全（视产品） |

### 互动图：`CpFtCompareFig`

- 两列对照，可点「CP」或「FT」高亮（初始 CP）。  
- 或上下切换同一张「生产链路」上的高亮段。  
- **结论句**：CP 省封装钱；FT 挡出货风险——两道都常见，不是二选一口号。

## 当堂判题

1. 封装的主要目的之一是？  
   - 取消所有测试 / **保护 Die 并引出可焊接管脚** / 把良率变为 100%  
   - 解释：见节 1。

2. FT 发生在？  
   - 仅硅锭阶段 / **器件封装完成之后** / 仅设计评审时  
   - 解释：Final Test。

3. BGA 的管脚形态更接近？  
   - 两侧金属插针 / **底部焊球阵列** / 只有天线  
   - 解释：图鉴。

4. CP 使用的典型接触方式是？  
   - 仅 USB 线 / **探针扎晶圆 pad** / 人眼观察  
   - 解释：针卡。

5. 封装键合不良可能导致？  
   - 设计公司改名 / **FT 失败（开路等）** / 光刻机停产  
   - 解释：封装缺陷要靠 FT 拦住。
