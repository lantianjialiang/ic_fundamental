## 节 1 · 时间轴（互动主图）

### 正文要点（侧栏随选中点展开）

| id | 短标 | 大约年代 | 侧栏正文 |
|---|---|---|---|
| tube | 真空管 | 上世纪上半叶 | 体积大、耗电高，系统靠人工与简易仪表检修，谈不上今天的 ATE。 |
| transistor | 晶体管 | 约 1940s–50s | 固态开关出现，电子系统开始小型化；测量仍以台式仪表为主。 |
| ic | 集成电路 | 约 1950s–60s | 多器件做进同一衬底，「一颗料」里功能变多，引出**批量自动测试**的需求。 |
| moore | 集成度上升 | 约 1960s 起 | 晶体管数量粗略按指数涨（示意即可）。管脚、状态空间一起涨，**穷举所有输入组合**很快不现实。 |
| foundry | 垂直分工 | 约 1980s–90s | Fabless + Foundry 模式兴起，设计与制造分离；封测也可外包给 OSAT（接 P01）。 |
| soc | SoC / 规模爆炸 | 约 2000s | 单芯片集成 CPU、存储接口、外设等；测试要分段、要 DFT，不能只靠外部穷举。 |
| chiplet | Chiplet / 先进封装 | 近年 | 多裸片进一封装，测试多了「已知好 Die (KGD)、封装后再测」等话题；本课点到为止。 |

- Chiplet：多片与互连良率，CP/FT/KGD 策略更复杂。

## 节 2 · 为什么穷举会垮（小互动）

### 正文

假设一颗纯组合电路有 \(n\) 个输入，穷举要 \(2^n\) 种图案：

- \(n=8\) → 256，还能手写或小脚本。  
- \(n=32\) → 约 43 亿，ATE 也测不完（时间与费用都不允许）。  
- 再算上时序状态，更不是「把真值表扫一遍」能解决的。

所以后来有：**结构化测试、Scan、ATPG、BIST**——名字先混个脸熟，做法以后课再讲。

### 互动图：`ExhaustExplodeFig`

- 滑条或分段按钮：输入位数 4 / 8 / 16 / 24（初始 4）。  
- 显示「组合数 ≈ \(2^n\)」以及一句判断：可穷举 / 勉强 / 不可能。  
- **结论句**：位数一多，必须换方法，不能死测真值表。

## 当堂判题

1. 集成电路出现之后，测试更需要什么？  
   - 只靠人眼看灯 / **自动、可重复的批量测量与判定** / 不再需要测试  
   - 解释：集成度上升，必须靠设备自动判 Pass/Fail。

2. 输入位数变多时，穷举所有组合会怎样？  
   - 永远可行 / **时间与成本迅速不可接受**  
   - 解释：\(2^n\) 增长。

3. Fabless + Foundry 分工大概带来什么？  
   - 取消封装 / **设计与制造可以分属不同公司** / 不再需要晶圆  
   - 解释：垂直分工。

4. Scan / ATPG 在本课的定位是？  
   - 本课要会手写 ATPG / **只预告：用来对付测不完的电路** / 与测试无关  
   - 解释：细节在后续轨。

5. Chiplet 让测试多考虑什么？（多选意图，做成单选即可）  
   - 只测一次就永远够 / **多片良率与封装后互连，常要 KGD + 再测**  
   - 解释：点到为止。
