## 开篇（2–3 段）

半导体产业不是「一家公司从沙子做到手机」。多数情况下，**设计、制造、封装测试**分属不同公司。搞不清角色，后面听到 Fabless、Foundry、OSAT 会对不上号。

本课目标：认地图、认角色。不讲财报，不背具体制程节点清单。

## 节 1 · 产业链地图（互动主图）

### 正文

一条常见主线：

1. **设计**（Fabless / IDM 设计部）：定规格、画电路、出网表与版图。  
2. **制造**（Foundry / IDM 晶圆厂）：把电路做到晶圆上。  
3. **晶圆测试 CP**：封装前筛坏 Die。  
4. **封装**（OSAT / IDM）：划片、装壳、引出脚。  
5. **成品测试 FT**：封装后再测，决定能不能出货。  
6. **出货**：给系统商 / 渠道。

旁边还有：**EDA 工具商**、**设备商**、**材料商**——不直接出芯片，但产业链离不了。

### 互动图：`IndustryChainFig`

- **形态**：纵向或横向可点选站点（类似 D01 产业链）。  
- **初始选中**：第一个站点「设计」。  
- **站点**（顺序即显示序）：

| id | 短标 | 侧栏说明 |
|---|---|---|
| design | 设计 | Fabless 或 IDM 设计部：规格、RTL/原理图、版图。产出给晶圆厂的是「要造什么」。 |
| fab | 制造 | Foundry 或 IDM Fab：光刻、刻蚀、薄膜、掺杂、金属……产出是整片晶圆。 |
| cp | CP | 晶圆测试：探针扎 pad，坏 Die 记进 Bin 图，避免封装废片。细节 → D01。 |
| osat | 封装 | OSAT 或 IDM：划片、键合/倒装、塑封、成管脚或焊球。 |
| ft | FT | 成品测试：Handler + Socket，功能/DC/AC 更全。细节 → D01。 |
| ship | 出货 | 按 Bin 编带/装盘，交给客户。 |
| eco | 生态 | 可点「旁路」：EDA、设备、材料——支撑整条链，不占主线格子也可做成第二行小芯片。 |

- **结论句（侧栏固定一句）**：换芯片类型，换的是规格和仪器；**产业角色这张图不变**。

## 节 2 · 四种常见角色

### 正文

| 角色 | 做什么 | 典型特点 |
|---|---|---|
| **Fabless** | 只设计，不建厂 | 把晶圆代工交给 Foundry，封测常交给 OSAT |
| **Foundry** | 只代工制造 | 接多家 Fabless 的单；先进/成熟工艺产线是核心资产 |
| **IDM** | 设计 + 制造（常还有封测） | 一条龙或部分外包；汽车、功率、模拟里仍多见 |
| **OSAT** | 封装 + 测试 | 接封测订单；很多测试工程师在这里上班 |

另外：**系统商**买芯片装整机；**分销商**做渠道。本课点到即可。

### 互动图：`RoleCardsFig`

- **形态**：四张可点选卡片（Fabless / Foundry / IDM / OSAT）。  
- **初始选中**：Fabless。  
- 选中后右侧（或下方）显示：一句话定义 +「货从哪进、从哪出」小箭头。  
- 可选：拖拽「设计稿 / 晶圆 / 封装件」到正确公司类型的投放区（简易），作巩固。

## 节 3 · 钱和风险在哪换手（点到为止）

### 正文

- **设计公司**承担：产品定义错了、卖不掉的风险。  
- **晶圆厂**承担：产线投资、良率波动（代工合同会写责任边界）。  
- **封测厂**承担：封装良率、测试逃逸（坏片流出）的压力。  
- **测试**本身不「修好」多数数字芯片，而是**判断** Pass/Fail，保护后道成本和客户。

不展开合同条款；一句带过：**良率就是钱**。

### 互动图：`RiskChipsFig`（可与节 2 合并减负）

- 三枚芯片：「定义风险 / 制造良率 / 逃逸风险」，点击高亮对应角色。  
- 若觉得与节 2 重复，实现时可并入 RoleCards 的说明段，本图可砍。

## 节 4 · 测试工程师站在哪

### 正文

常见岗位落点：

- Foundry 或 IDM 的 **CP** 团队  
- OSAT 或 IDM 的 **FT** 团队  
- 芯片公司内部的 **产品工程 / 测试开发**（写程序、做表征，不一定天天站产线）

## 当堂判题

1. Fabless 公司通常自己建先进制程晶圆厂吗？  
   - 对 / **错**  
   - 解释：Fabless 以设计为主，晶圆多交 Foundry 代工。

2. OSAT 主要做什么？  
   - 只做 EDA 软件 / **封装与测试** / 只卖硅片原料  
   - 解释：OSAT = Outsourced Semiconductor Assembly and Test。

3. 晶圆测试（CP）通常发生在封装前还是封装后？  
   - **封装前** / 封装后  
   - 解释：先筛坏 Die，再决定要不要花钱封装。

4. 下面哪个最像 IDM？  
   - 只设计手机 SoC、晶圆全外包 / **自己有设计团队也有晶圆厂（或长期深度整合制造）** / 只提供光刻机  
   - 解释：IDM 覆盖设计与制造（封测可自有可外包）。

5. 测试的本职更接近？  
   - 把坏电路改成好电路 / **判断 Pass/Fail，拦住坏片**  
   - 解释：与 D01 口径一致；存储 Repair 是例外，本课不展开。
